# HoneSight

HoneSight 希望成为摄影新手身边简单、实用的成长伙伴。它不会只告诉你一张照片“好不好”，而是结合你的创作目标，分析画面中的曝光、对焦、构图与色彩，并给出可以直接尝试的拍摄和修图建议。无论是记录生活、经营社交平台，还是逐步形成自己的摄影风格，都可以从这里获得启发。

## 功能介绍

### 首页与每日摄影灵感

首页每日推荐精选摄影作品，帮助用户发现不同的拍摄题材、构图方式和色彩风格，为下一次创作寻找灵感。

### 照片分析报告

上传照片后，系统会从曝光、对焦、构图和色彩等方面进行分析，并结合目标风格给出评分、问题说明以及具体的拍摄和修图建议。

### AI 摄影教练（每周一练）

AI 摄影教练会根据用户的摄影偏好提供每周练习主题和拍摄任务，帮助用户通过持续实践掌握摄影技巧、培养观察能力。

### 个人作品集

用户可以集中保存和管理自己的摄影作品，随时查看照片与分析结果，记录个人的摄影成长过程。

### 摄影社区

用户可以在社区发布自己的摄影作品，浏览其他摄影爱好者的创作，并通过点赞、评论等方式交流拍摄经验、分享灵感。
